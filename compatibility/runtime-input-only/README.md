# Native input-only candidate projection

Authority is the fixed Runtime's native `thread/inputOnlyPolicy/read` schema, generated by `yijie-codex`'s dedicated `make input-only-build`. This is a local FEAT-155 candidate; it does not replace the released Runtime projection or enable experimental APIs.

Run `make runtime-input-only-generate`, then `node scripts/sync-runtime-input-only.mjs`, and `make runtime-input-only-check`. The generator validates the exact patch order, patch digests and complete schema tree against the candidate manifest. It mechanically projects the native request/response into Go and JSON Schema, records source/generator hashes, and supplies exact binary/manifest pins to Host. Do not edit generated files. The only consumer is `yijie-agent-host/internal/codex`; Desktop still consumes its existing draft contract.

An ordinary thread returns a null policy. A restricted thread's receipt is evidence bound to the loaded native thread; it is not authorization by itself. Host must verify exact artifact, managed configuration, generation, thread, directory, policy version and every restriction before use. Missing/unknown policy facts fail closed.

Deploy Runtime before its projection and Host consumption. Existing Runtime support remains for ordinary sessions; drafts stay unavailable with that artifact. Rollback disables new draft production while retaining compatible data readers and history. Local source locks identify dirty candidate material and are not a production tag, consumer-owner approval or release pin. Overall FEAT-155 impact is conservatively breaking; old public Host wire and native method responses remain unchanged.
